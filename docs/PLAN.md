# Interpretability scope

Stockfih v1 is a search-interpretability web workspace: PGN Review and FEN
Explore, reliable browser Stockfish, every game/PV ply inspectable, real depth
traces, same-root comparisons/refutations and evidence export. Optional AI
selects checked facts through direct BYOK/local-compatible requests.

Implemented mechanics and acceptance evidence are in RELEASE.md,
AUDIT-STATUS.md and ARCHITECTURE.md. The cached local Qwen model passed a real
browser test; hosted live calls were waived. Production promotion awaits owner
review of a preview. Finish this release before adding features.

Search evidence does not establish a cognitive reasoning process or causal
network attribution. NNUE interventions require a separate feasibility and
claim-validation study after v1; they do not block release. More providers,
accounts, social features and game-service imports are outside this release.

Tutoring, coaching, drills, Socratic prompts, learner memory and profiles are
excluded permanently unless the owner explicitly changes the scope. Review
and Explore remain useful without any model.
